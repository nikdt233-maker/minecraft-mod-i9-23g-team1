## Цель проекта

Разработать мод для Minecraft на платформе Fabric, добавляющий блок «Батарея».

Установленный блок восстанавливает здоровье игрока, находящегося в радиусе 5 блоков
(0,5 единицы здоровья в минуту).

## Структура проекта

- `src/main/java` — исходный код мода (Java). Здесь находится класс точки входа
  `ru.college.i923g.zhkh123mod.Zhkh123Mod`.
- `src/main/resources` — ресурсы мода: конфигурационный файл `fabric.mod.json`
  (идентификатор мода и точка входа), а в дальнейшем текстуры, модели, рецепты и переводы.
- `build.gradle` — сценарий сборки (плагины, зависимости, настройки Java).
- `settings.gradle` — имя проекта и адреса репозиториев плагинов.
- `gradle.properties` — параметры проекта: версии Minecraft, Fabric и мода.

## Игровой объект

- Тип объекта: блок.
- Рабочее имя: `battery` (Батарея).
- Идентификатор: `zhkh_123mod:battery`.
- Назначение: блок-радиатор, который лечит игрока в радиусе 5 блоков.
- Получить в тестовом клиенте: `/give @s zhkh_123mod:battery`.
