# Minecraft-мод «ЖКХ_123Mod»

Мод для Minecraft (Fabric), добавляющий блок «Батарея» — чугунный радиатор, рядом с которым
медленно восстанавливается здоровье игрока. Учебный проект группы И9-23Г по дисциплине
«Инструментальные средства разработки программного обеспечения».

## Блок «Батарея»

- Идентификатор: `zhkh_123mod:battery`, русское название — «Батарея».
- Свойства: прочность как у железного блока (`3.0` / `6.0`), уровень света 8,
  предмет выпадает только при добыче киркой не хуже каменной.
- Получение: творческий инвентарь (вкладка «Строительные блоки»), команда
  `/give @s zhkh_123mod:battery` или крафт.

## Версии и совместимость

| Компонент     | Версия           |
|---------------|------------------|
| Minecraft     | 1.21 (проверено только на ней) |
| Fabric Loader | 0.19.3 или новее |
| Fabric API    | 0.102.0+1.21     |
| Java          | 21               |
| Мод           | 1.0.0            |

Другие версии Minecraft не проверялись, их поддержка не обещается.

## Установка

1. Установите Minecraft 1.21 и создайте отдельный профиль Fabric Loader 0.19.3 или новее
   (https://fabricmc.net/use).
2. Откройте папку `mods` (Windows: `%APPDATA%\.minecraft\mods`; если её нет, создайте).
3. Поместите в неё Fabric API `fabric-api-0.102.0+1.21.jar`.
4. Удалите из `mods` старые файлы `zhkh-123mod-*.jar`, если они там есть.
5. Поместите в `mods` файл мода **`zhkh-123mod-1.0.0.jar`**.
6. Запустите игру с профилем Fabric и создайте мир. Блок «Батарея» должен быть во вкладке
   «Строительные блоки»; в журнале запуска есть строка «Проект загружен успешно».

## Использование

- **Получение:** творческий инвентарь, `/give @s zhkh_123mod:battery` или крафт.
- **Рецепт (верстак 3×3):** верхний и нижний ряды — 3 железных слитка, средний ряд — 3 редстоуна.
  Итого 6 железных слитков и 3 редстоуна.
- **Лечение:** если рядом (в радиусе 5 блоков) стоит батарея, раз в минуту игроку с неполным
  здоровьем восстанавливается 0,5 единицы здоровья.
- **Сообщение:** правый клик пустой рукой по батарее выводит в чат «Батарея тёплая.».
- **Пример:** поставьте батарею, получите урон командой `/damage @s 6`, встаньте рядом и
  подождите около минуты; проверить здоровье можно командой `/data get entity @s Health`.

## Сборка из исходников

```
.\gradlew.bat clean build
```

Готовый файл — `build/libs/zhkh-123mod-1.0.0.jar` (файл `-sources.jar` не использовать).

## Известные ограничения

- Наличие воды в батарее не моделируется: батарея лечит всегда, а не только при заполнении водой.
- Обогрев игрока (тепло) не реализован, мод только восстанавливает здоровье.
- Проверено только на Minecraft 1.21 с Fabric API 0.102.0+1.21.
- Возможное развитие: добавить состояние «заполнена водой» и постепенный расход воды.
