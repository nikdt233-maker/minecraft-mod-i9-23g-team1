# Minecraft-мод «ЖКХ_123Mod»

Учебный проект команды по дисциплине «Инструментальные средства разработки программного обеспечения».

## Команда

Группа: И9-23Г

Участники:

- Дятчин Н.А.
- Устинов С.А.
- Чечков В.А.


## Цель проекта

Разработать мод для Minecraft на платформе Fabric, добавляющий блок «Батарея».
Установленный блок восстанавливает здоровье игрока, находящегося в радиусе 5 блоков
(0,5 единицы здоровья в минуту).
